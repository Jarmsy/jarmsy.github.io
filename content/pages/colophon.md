This site is a folder of plain-text files — markdown for the writing, small YAML lists for the rest — turned into static pages by [Astro](https://astro.build). No database, no tracking, no analytics. The little JavaScript there is runs the light/dark switch, the filters, the shuffle buttons and the photo viewer; every page works without it.

Type is set in [Newsreader](https://fonts.google.com/specimen/Newsreader) for reading and [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) for dates, labels and stamps. Every page shows when it was last touched.

Some drafts on this site were written with help from AI tools; the positions, the edits and the mistakes are mine.
