This is a sample longer-form piece — delete it once you've written a real one.
It exists to show what your writing will look like, and to demonstrate the
formatting tools you have.

## Plain markdown covers most of it

You can write **bold**, *italics*, [links](https://example.com), lists:

- like
- this

> and pull quotes, which look like this.

## Figures and visuals

Drop an image next to this file and reference it with regular markdown, or use
the `Figure` component for a consistently styled caption:

<Figure
  src="/images/sample-figure.svg"
  alt="A placeholder chart"
  caption="Figure 1: A completely real chart proving the point beyond doubt."
/>

That's it. One file per piece, images alongside it, and the site handles the
rest.
